# Agent Instructions

## Required Project Rules

Before planning or modifying code in this repository, read and follow `DEVELOPMENT_RULES.md`.

After every code modification, perform the **Automatic Post-Change Review** defined in `DEVELOPMENT_RULES.md` before reporting the work as complete. This review is mandatory and does not require a separate user request.

Do not treat passing tests as a substitute for reviewing regression impact, code placement, logical correctness, concurrency safety, scope, verification quality, and documentation consistency.
